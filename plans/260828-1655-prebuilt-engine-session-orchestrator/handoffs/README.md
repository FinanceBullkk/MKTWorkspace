# Handoff directory

One handoff is the context bridge to the next fresh session. Keep it short and operational:

- completed work and exact evidence paths;
- current verdict and why;
- files changed and files intentionally protected;
- environment/engine/version/hash facts that affect reproducibility;
- the single next action and its entry gate;
- unresolved questions or blockers.

Do not paste the old conversation or raw logs. The next session reads this handoff plus its phase
file and the README only.
